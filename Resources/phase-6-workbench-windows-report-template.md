- 候选身份：
- Git 提交：
- Windows 版本：
- 初始/最终缩放：
- 输入 checksums：通过/失败
- source：通过/失败
- win-unpacked：通过/失败
- installed mode：通过/失败
- 100% / 125% / 150% 冷启动：
- 动态 DPI：
- v1 目录 / v2 ZIP / 危险 ZIP：
- 真实桌宠启动停止及退出清理：
- 产品配置、导出、任务恢复：
- 覆盖/重试：
- 官方卸载与重装：
- 最终精确进程数：
- 截图、日志和产物路径：
- 未通过项与未受影响范围：

结论必须三选一：Windows installed-mode 通过 / Windows 验收失败 / Windows 验收未完成。不得用静态或 macOS 证据代替。
