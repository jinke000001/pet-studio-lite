# Phase 6.2 PRD：导入、检查与预览闭环

## 问题

Phase 6.1 只能创建和恢复制作项目。内部制作人员仍需通过终端导入宠物包、读取校验报告、查看联系表与动作预览，并手动启动真实桌宠，尚未形成工作台内的第一个完整闭环。

## 成功标准

- 无需终端完成“选择本地目录或 ZIP → 导入 → 检查 → 联系表/动作预览 → 启动并停止真实透明桌宠”。
- 合法 v1 目录和合法 v2 ZIP 均可导入、持久化并在工作台重启后恢复。
- 危险 ZIP、符号链接、路径逃逸、超限文件和无效包继续由现有唯一校验管线拒绝。
- 检查结果明确区分通过、警告和阻断，并提供中文原因、未受影响范围与下一步动作。
- renderer 不接触、提交或持有绝对路径，不获得 Node、shell、任意文件或通用 IPC 能力。
- 普通 `npm run pet -- <selector>` 的产品选择、行为和用户数据身份保持不变。

## 范围

- macOS 原生目录和 ZIP 选择器。
- `unknown`、`internal-test`、`authorized` 三种授权状态。
- 主进程派生安全来源标识并复用现有 directory/ZIP importer。
- 导入摘要、检查结果、步骤状态和最近成功结果的原子持久化与恢复。
- 安全展示宠物身份、v1/v2、图集规格、alpha、动作能力、来源摘要、授权状态、联系表和逐动作动画。
- 当前项目最近一次成功导入的真实桌宠启动、停止与单实例生命周期。
- 失败后的安全重试；失败不得覆盖上一次成功结果。

## 排除项

- Petdex slug 网络导入、后台任务中心、取消和任务恢复（Phase 6.4）。
- 产品配置、标准包/项目包/候选导出（Phase 6.3）。
- Kimi 最终视觉收口（Phase 6.5）。
- 工作台候选打包和 Windows installed-mode 验收（Phase 6.6）。
- AI 动作生成、逐帧编辑、签名、公证、商城、支付、DRM、自动更新和正式发布。

## 约束

- 文件来源只能由主进程原生选择器获得；renderer 只提交来源类型、授权状态和项目 ID。
- 导入输出固定进入当前项目的版本化、非覆盖工作区。
- UI 不复制导入、ZIP 安全或宠物包校验规则。
- Phase 6.1 项目向后兼容，升级后仍可打开和恢复。
- 同时最多一个工作台预览；切换项目、停止、退出或父进程消失时必须清理。
- `unknown` 与 `internal-test` 不得展示为可分发。

## 受保护边界

- 不修改或覆盖 Wukong 只读交付、用户 Codex/Petdex 宠物目录、`local-pets/` 五个现有宠物、原始素材、批准图集、历史候选、release 历史、RETURN 或 T7 证据。
- 不改变现有产品配置、NSIS 修复和普通桌宠入口的默认路径。
- 新产物只写入当前工作台项目的新版本目录；失败半成品不能成为项目成功状态。

## 实施步骤

1. 扩展项目契约和存储，加入导入、检查与预览状态，并提供 Phase 6.1 项目兼容升级。
2. 增加主进程原生选择器和导入控制器，路径只在受信主进程内流动。
3. 映射导入错误为中文通过/警告/阻断结果，并原子保存最近成功导入。
4. 以项目成功导入记录为唯一资源根，向 renderer 暴露受限预览数据。
5. 增加复用现有 runtime 的工作台预览启动器和父子进程清理。
6. 接入 React 导入、检查、联系表、动作与真实桌宠控制界面。
7. 完成自动化、macOS 真实运行、审查、证据、MEMORY 和 checkpoint 提交。

## 验证计划

- 契约/存储：兼容升级、成功保存、失败不覆盖、篡改和路径逃逸拒绝。
- 导入：合法 v1 目录、合法 v2 ZIP、重复导入；危险 ZIP、符号链接、超限和无效包拒绝。
- IPC/资源：renderer 无路径参数；只允许当前项目最近成功导入的预览资源。
- 预览生命周期：单实例、停止、项目切换、工作台退出和父进程消失清理。
- 自动门：`npm test`、`npm run studio:typecheck`、`npm run studio:build`、`npm run lint`、`npm run source:preflight`、`npm audit`、`git diff --check`。
- macOS 真实门：隔离 userData；Doraemon v1 目录、Dai v2 ZIP、危险 ZIP；联系表、动作推进、透明桌宠启动/停止、完整重启恢复；920×620、1180×760、1440×900 可用性检查。
