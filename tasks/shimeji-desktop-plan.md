# Shimeji 桌面运行时实施计划

1. 冻结规范、第三方来源和许可证边界。
2. 以测试驱动建立桌面平台、窗口边缘和基础运动核心。
3. 建立 Windows 只读窗口桥，并在真实 Windows 上证明坐标与 DPI 一致。
4. 接入现有 `PetWindowHost`，完成“走到窗口 → 攀爬 → 站上窗口 → 窗口消失后坠落”的纵向样板。
5. 搬运经典动作序列、行为权重和拖拽投掷物理。
6. 增加多宠物与传统 Shimeji 包安全导入。
7. 接入工作台配置、预览和 Windows 便携 ZIP 导出。
8. 完成 Windows 10/11、多显示器、DPI、长稳和打包验收。

每完成一个纵向增量，必须保持 `npm test`、类型检查和串行构建通过。Windows 行为只有在 Windows 实机运行后才能标记完成。
