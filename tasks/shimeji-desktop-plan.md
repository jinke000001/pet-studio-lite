# Shimeji 桌面运行时实施计划

## 当前分阶段顺序

1. **基础体验收口**：修复边缘横滑、透明窗口碰撞间距、移动突跳和攀爬动画；输出新的 Windows 内测包并实机复验。
2. **真实角色兼容**：以 Mario 经典 Shimeji 包作为 `internal-test-only` 样本，先预览资源与授权信息，再通过安全转换链路导入并生成兼容报告。
3. **应用窗口互动**：验证“行走 → 碰侧边 → 攀爬 → 落在顶边 → 窗口移动/最小化/关闭后跟随或坠落”的完整链路。
4. **多显示器与 DPI**：明确双屏操作步骤，验证负坐标、跨屏拖动、100%/125%/150% 与混合 DPI 下的 bottom-center 锚点。
5. **经典生态扩展**：按兼容报告补齐高价值动作和安全 XML 子集；无法可靠映射的表达式保留为后续扩展，不执行原始动态代码。
6. **产品化验收**：完成 Windows 10/11、长稳、并发多宠物、退出/残留进程、打包与分发权利检查。

每完成一个纵向增量，必须保持 `npm test`、类型检查和串行构建通过。macOS 冒烟、单元测试和 ZIP 静态检查只能证明候选可测；Windows 行为只有在对应实机证据保存后才能标记完成。
