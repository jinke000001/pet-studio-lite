## 订阅判断原则

- 先比较“完成相同结果所需的用户精力”，再比较总耗时。
- 遇到平台边界时，如实停止和清楚说明优于伪造完成。
- 第一次任务只代表工程纵向切片；最终订阅建议至少再比较一次 Bug 修复任务和一次 UI 打磨任务。
