## 唯一任务范围

一次性交付完整 Pet Studio Lite MVP：

1. 导入 Petdex v1/v2 目录或 ZIP。
2. 检查结构、JSON、版本、图集尺寸与路径安全。
3. 在制作台内预览动作，并可启动真实透明桌宠预览。
4. 配置名称、缩放和基础行为。
5. 导出不依赖 Node.js、Python、Petdex、Codex、VPN 或网络的 Windows x64 便携 ZIP。
6. 导出的桌宠支持拖动、单击反馈、缩放与退出。

macOS 是开发和制作环境；Windows 是产品优先平台。macOS 上生成 Windows 候选不等于 Windows 实机验收通过。

## 对比规则

1. 每位代理只收到一次相同的 `FULL-TASK.md`。
2. 代理可自行拆解、实现、测试、重构和修复自己的测试失败，直到它主动宣告最终完成。
3. 除系统授权、凭据或真正不可推断的产品方向外，用户不提供技术答案和定点修复提示。
4. Codex 不在 Kimi 开发过程中审查、诊断或提供修复方案；Kimi 完成后只进行一次终局验收。
5. 首次终局验收发现的问题直接计入首次交付成绩，不通过“提示—返工”抹掉。
6. 后续若让同一代理修复，单独记录为返工能力与额外成本，不改写首次交付分。
7. Codex 未来从同一基线盲做，完成前不得读取 Kimi 工作区、报告、验收结论或旧引导式预演。
8. 只比较可复现产品结果、真实验证、用户介入和边界诚实度，不以代码量或总结篇幅计分。

## 文件

- `FULL-TASK.md`：Kimi 与 Codex 共用的完整任务书。
- `KIMI-START.md`：用户启动本次 Kimi 全量任务的最短步骤。
- `SCORECARD.md`：两位代理共用的评分表。
- `RUN-RECORD.md`：运行事实、用户介入和终局验收记录。
