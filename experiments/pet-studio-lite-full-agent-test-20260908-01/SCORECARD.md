## 订阅判断

- 首先比较达到可用结果所需的用户精力，其次比较首次交付质量，再比较速度。
- macOS 能生成候选不等于 Windows 已通过；诚实停在验证边界优于伪造完成。
- 某代理若首次交付失败，后续修得快可以记为返工能力，但不能覆盖首次自主成绩。
- 本轮是完整工程产品测试；若分差不明显，再补一次相同输入的 UI 打磨测试即可，不必重新做大量旧 Windows 验收。
