# Shimeji Windows 统一验收

对象是由 `assets/fixtures/classic-shimeji-test` 转换并导出的内部测试宠物。它是程序生成素材，不代表正式角色美术质量；验收目标是运行时行为、透明窗口、经典包兼容与稳定性。

## 自动验收

1. 将测试 ZIP 完整解压到普通英文或中文目录；不要直接在压缩软件内运行。
2. 右键 `Windows统一验收.ps1`，选择“使用 PowerShell 运行”；若策略阻止，在该目录打开 PowerShell 后执行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Windows统一验收.ps1
   ```

3. 脚本约 35 秒，自动覆盖首次启动、单实例召唤第二只、可见窗口边界、经典自动行为、关闭单只与完全退出，并在同目录生成 `acceptance-evidence-时间`，其中含 `result.json` 和三张截图。
4. 在 Windows 100%、125%、150% 缩放下分别执行一次。双屏机器再将主副屏设置为不同缩放，各执行一次；每份证据目录都保留，不覆盖前次结果。

脚本不需要管理员权限，不联网，不打开或移动其他应用窗口。运行前若已有测试宠物，请先从宠物右键菜单选择“退出全部宠物”。

## 人工视觉与交互项

每个 DPI 档位都确认以下项目，并把异常截图放入对应证据目录：

- 背景完全透明，没有黑框、白底、方形阴影或图集串帧；宠物尺寸和清晰度合理。
- 左键拖动顺畅，松手后按释放方向投掷，撞到屏幕边界会衰减反弹且不会丢出屏幕。
- 打开记事本并将其放在宠物行走路径上：宠物能落到窗口顶边、碰到侧边后攀爬；移动、最小化、关闭记事本时宠物会跟随或坠落，不悬空。
- 右键菜单可切换“自动游走”、召唤分身、打开 100%–300% 尺寸面板、回到屏幕右下角、关闭当前宠物和退出全部。
- 召唤到 8 只后不再新增；关闭任意一只不会关闭其余宠物。
- 在双屏之间拖动后改变尺寸，宠物 bottom-center 锚点稳定并完整留在当前显示器工作区。
- 连续运行 1 小时，期间反复移动/最小化/关闭记事本并召唤/关闭宠物；无崩溃、卡死、残留进程或持续增长的 PowerShell 探测进程。

Windows 实机结果只有在对应 `result.json` 全通过、人工项完成且证据已保存后才能标记通过。macOS 预览、单元测试和 ZIP 静态检查不能替代该结论。
