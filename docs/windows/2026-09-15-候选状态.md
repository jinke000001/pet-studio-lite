# 0.2.0-beta.1 双平台候选状态

## 已实现

- 同一工作台代码支持 Mac 与 Windows x64；普通使用不调用外部 Node/npm。
- 官方在线导入使用受限 HTTPS 下载、会话候选预览与一次性确认，取消/确认后清理临时下载。
- Windows 桌宠导出使用随包运行时模板；检查版本、SHA-256、素材快照与源码模式的模板新鲜度，输出不覆盖已有文件。
- 打包时独立安装目标平台 sharp 依赖；构建与签名在临时目录完成，产物版本化保存。
- 修正文件 URL 编码；单实例工作台；Windows 关闭工作台会关闭其预览。

## 本次证据

- npm test：全部通过（45 包校验、19 ZIP、10 命令、310 运行时、8 下载测试，以及素材快照、运行时构建、Windows kit、离线导出专项）。
- 主工程及新增构建/检查脚本 TypeScript 检查通过。
- 源码模式真实工作台回归：52/52。
- Mac arm64 打包应用：空 PATH、隔离数据、真实 WebP 导入、配置、已解码精灵预览、离线 Windows ZIP 导出、官方 Boba 下载/确认、防令牌复用、单实例、正常退出及完整重启保留数据，14/14。
- Mac 打包应用实际导出的 Windows 桌宠 ZIP：静态核验 33/33。
- Windows 工作台 ZIP：194 条目 CRC 全部通过；EXE x64/产品名/版本、目标平台 sharp/libvips、模板哈希/版本、asar 入口与不含外部 builder 校验通过。
- 独立代码审查发现的旧帮助文案、隔离重启入口、候选证据绑定和 PowerShell 参数集问题均已修复。

## 尚未完成
