# 新手教程：从下载到第一只桌宠

你不需要会写代码，也不用安装 Node.js、Python、Git 或运行终端命令。Windows 用户可以直接在 Windows 上完成全部操作。

## 0. 先看下载状态

**安装包正在准备公开，目前尚未发布。** 因此，你现在在 GitHub 找不到 EXE/DMG 是正常的，不是操作错误。发布前请向维护者获取体验包；维护者可在 Releases 中查看发布草稿。

公开后，安装包会出现在 [版本与安装包页面（Releases）](https://github.com/jinke000001/pet-studio-lite/releases)。下文介绍发布后的下载方式，以及拿到体验包后的完整操作。

## 1. 在 GitHub 找到正确的安装包

1. 打开上面的 **Releases** 链接；也可以在仓库首页右侧找 **Releases**。
2. 找到 `Pet Studio Lite 0.2.0-beta.2 体验版`。`Pre-release` 表示体验版。
3. 往下找到 **Assets**（附件），如果折叠着，点开它。
4. 按下表下载一个适合电脑的文件，保存到“下载”文件夹。

| 你的电脑 | 应下载的文件 |
| --- | --- |
| Windows 11，Intel/AMD 64 位电脑 | `PetStudio-Lite-0.2.0-beta.2-Windows-x64-Setup.exe` |
| Mac，M1/M2/M3/M4 等 Apple Silicon 芯片 | `PetStudio-Lite-0.2.0-beta.2-Mac-arm64.dmg` |

不知道 Mac 芯片型号：点左上角苹果菜单 → **关于本机**，查看“芯片”。写着 Intel 的 Mac 不适用本次安装包。Windows ARM 电脑尚未验证。

**不要下载 `Source code (zip)` 或 `Source code (tar.gz)` 来安装程序。** 那是给开发者的源码，绿色 **Code → Download ZIP** 也是源码。`SHA256SUMS.txt` 用于校验下载完整性，不是启动程序。

## 2A. Windows 安装与打开

1. 打开文件资源管理器，进入“下载”。
2. 双击下载的 `PetStudio-Lite-0.2.0-beta.2-Windows-x64-Setup.exe`。
3. 按安装向导选择安装位置并完成安装。
4. 从桌面快捷方式或开始菜单打开 **Pet Studio Lite**。
5. 看到左侧“导入、检查、预览、配置、导出”五个步骤，说明工作台已启动。

当前体验版没有代码签名。如果 Windows 显示“Windows 已保护你的电脑”，先核对下载来自本仓库的 Releases；确认来源后可点击“更多信息 → 仍要运行”。如果学校/公司的策略禁止安装，请联系管理员，不要关闭系统安全功能。

安装完成后无需保留连接 T7。不要把安装程序 EXE 和后面导出的桌宠 EXE 混淆。

## 2B. Mac 安装与打开

1. 在 Finder 的“下载”中双击 `.dmg` 文件。
2. 将 **Pet Studio Lite** 拖到 **Applications（应用程序）**。如果窗口中没有 Applications 快捷方式，就拖入 Finder 左侧“应用程序”。
3. 在“应用程序”里双击 **Pet Studio Lite**，以后也从这里打开。
4. 看到五步工作台后，可以推出 Finder 侧栏里的安装磁盘。

当前 Mac 体验包尚未公证。若提示无法验证开发者，确认来自本项目后，打开“系统设置 → 隐私与安全性”，在该应用的阻止提示处选择“仍要打开”。若提示文件损坏或出现其他错误，保留提示截图并反馈，不要自行执行网上的解除安全限制命令。

Mac 能预览桌宠，但本工作台目前导出的独立桌宠是 **Windows 程序**。

## 3. 导入第一只宠物：以 Boba 为例

1. 在工作台左侧点击 **导入**。
2. 找到 **从 Petdex 下载** 区域。
3. 把下面这一整行复制到该区域的输入框：

```text
npx petdex@latest install boba
```

4. 点击 **下载并读取信息**，等待宠物信息和动画预览出现。此步骤需要联网。
5. 核对宠物后，点击 **确认导入**。
6. 导入完成后，左侧最近项目中会出现它，工作台进入检查步骤。

**上面的文字粘贴在工作台内，不要粘贴到 PowerShell、终端或浏览器地址栏。** 工作台只读取其中的宠物名称，不会执行 npx。

已有素材也可以用“选择 Petdex 目录”或“选择 ZIP 压缩包”导入。应选择包含 `pet.json` 和图集的文件夹，不能只选一张图片。

## 4. 检查和预览

1. 在 **检查** 页确认结构检查通过。有红色错误时，先按提示解决。
2. 点击左侧 **预览**，选择待机、行走等动作，看宠物是否完整。
3. 可以暂停，用上一帧/下一帧逐格查看；发现碎片时，先确认是否已存在于原素材。
4. 点击 **打开桌宠预览**，桌面上会出现可拖动的宠物。它是预览，关闭工作台时会一起关闭。

结构检查通过表示文件格式可用，不保证每一帧绘画都没有问题。

## 5. 保存配置

1. 点击 **配置**。
2. 设置显示名称、大小，以及是否允许自动游走。
3. 点击 **保存配置**，看到保存成功的提示后继续。

如果导出按钮不可用，先检查是否有未保存的修改。项目保存在当前电脑，GitHub 不会自动帮你同步项目。

## 6. 导出并在 Windows 上运行

1. 点击 **导出**。
2. 点击 **选择导出位置并导出**，例如选择桌面的一个新文件夹。
3. 等待成功提示，找到生成的 `petlite-pet-…-win-x64-….zip`。
4. 在 Windows 上右键该 ZIP → **全部解压缩** → **提取**。
5. 打开解压后的文件夹，双击 **PetLitePet.exe**。不要在压缩包预览窗口中直接运行，也不要只把 EXE 单独移出去。
6. 桌宠出现后，可以拖动；右键菜单可改大小、控制游走或选择 **退出全部**。

工作台安装包已包含导出所需运行时，无需另装开发工具。Mac 用户请把导出的 ZIP 复制到 Windows 电脑后运行。

本地体验与对外分发是两件事：请遵守宠物素材的授权。标为 `internal-test-only` 的产物仅用于内部测试；软件能导出不代表角色素材获得了分发许可。

## 7. 遇到问题怎样反馈

打开仓库的 [Issues（问题反馈）](https://github.com/jinke000001/pet-studio-lite/issues)，登录 GitHub 后选择 **New issue**。按下面格式填写即可：

```text
电脑系统：例如 Windows 11 / Mac M2
工作台版本：0.2.0-beta.2
下载的安装文件名：
宠物名称或 Petdex 命令：
操作步骤：我先点了……然后……
预期：我希望出现……
实际：出现了……
截图或报错原文：
```

发截图前请遮住不想公开的个人信息。当前是体验版，部分专项验证仍未完成；遇到问题保留现场后反馈即可。
